# Критерии Вайбатона → доказательства

Ориентир — переданные изображения критериев: техническая реализация 35, продуктовая проработка 30, польза для Владивостока 20, креативность/презентация 15. Ниже реализованные свидетельства, а не самостоятельная оценка баллов.

| Критерий | Реализация | Доказательство / состояние |
| --- | --- | --- |
| Работоспособность MVP (12) | Публикация → подбор → круг → три личных подтверждения → резерв | `tests/krug.spec.ts`: полный путь на MUI и F7, реальные MongoDB и cookie-сессии |
| Технические решения (8) | Слои domain/service/repository, явное направление графа, версии и ограничения | `architecture.md`, чистые тесты, измерение 12/120/250 заявок |
| Как применяли ИИ (10) | Разработка и анализ с последующей проверкой инвариантов | `ai-usage.md`: конкретные ошибки и исправления, воспроизводимые команды |
| Надёжность и безопасность (5) | Владельцы, строгие схемы, hash сессий, Mongo-транзакции, ограничения CRUD | 10 интеграционных тестов: чужие действия, конфликты, истечение, ввод, reset |
| Кто пользователь и проблема (8) | Житель с ненужной вещью и встречным пожеланием | `product-decisions.md`; гипотеза описана, интервью пока не проводились |
| Качество решения и сценария (12) | Понятный личный результат, одна форма, схема и статусы, новый путь после отказа | Экраны заявки, matches, circle; браузерный отказ B→альтернатива E/D |
| Осмысленность решений (10) | Текстовые заявки, максимум 4 человека, резерв после общего согласия | Таблица компромиссов в `product-decisions.md`, ограничения в README |
| Значимость городской задачи (8) | Повторное использование вещей и поиск непрямых связей | Локальный сценарий понятен; реальный масштаб проблемы ещё не измерен |
| Применимость в городе (8) | Зоны Владивостока, самовывоз, пересечение времени и районов | Общая совместимость тестируется, интерфейс работает в часовом поясе города; маршруты не рассчитываются |
| Как измерить результат (4) | Уникальное покрытие прямыми и 2–4 кругами, просмотры/ответы/отказы | `/api/krug/metrics`, таблица на главной, план добровольного пилота |
| Понятная история | «Прямой пары нет → новая заявка → круг → согласия» | `demo-script.md`, воспроизводимый seed 12 пользователей + 11 заявок |
| Наглядная демонстрация | Реальная SVG-схема с ориентированными стрелками и текстом | `/circles/:id`, данные берутся из API; скриншоты `.local/qa/` |
| Сильные ответы | Границы, масштаб, ИИ, отказ, проверка спроса | Краткие ответы в конце сценария защиты |
| Осмысленная оригинальность | Мотив круга объясняет передачу, а не скрывает бизнес-логику | M3-токены, личный исход, текстовый эквивалент схемы; просмотр командой ещё нужен |

Согласованный круг не равен переданной вещи. Расчёт на демоданных не выдаётся за статистику Владивостока; найденные пересекающиеся круги не объявляются одновременно выполнимыми обменами. Следующий продуктовый шаг — добровольный пилот с отдельным подтверждением физических передач.

# Реализация «Круга»

Задание: `krug-codex-prompt.md`. Интерфейс: Framework7 React (мобильный, Material) и MUI (десктоп), общие API и данные. Существующий Data Studio сохраняется на `/studio`.

| Этап | Статус | Критерий проверки |
| --- | --- | --- |
| Основа и сохранность данных | Готово | Студия на `/studio`, защищённые доменные коллекции, локальный replica set без удаления текущей базы. |
| Домен и алгоритм | Готово | Циклы 2/3/4, ориентация, ограничения и ожидаемый набор A–L проверяются чистыми тестами. |
| MongoDB, сессии, API | Готово | Сохранение и транзакционное согласование, проверка владельца, отказ, отмена, истечение, конкурентные подтверждения. |
| Интерфейс | Готово | Каталог, формы, мои заявки, поиск, схема и ответы в обеих оболочках. |
| Интеграционные и браузерные проверки | Готово | Основной сценарий и отказ с альтернативой, сохранение данных, мобильная версия и Data Studio. |
| Документация и защита | Готово | README, API, архитектура, AI usage, критерии и воспроизводимый показ. |

## Исходное состояние

- Рабочая ветка `main`; пользовательские изменения `AGENTS.md`, `.agents/`, `docs/` сохраняются.
- Предметная область обменов ещё не реализована; имеется Data Studio и девять интеграционных проверок.
- Локальная MongoDB запускается отдельным процессом; исходный режим standalone требует перехода к replica set для транзакций.

## Решения

- Разделяем визуальные оболочки и общий контроллер/модель клиента; Next.js владеет веб-адресами.
- Согласование всех участников означает интерес, а не физическую передачу вещи.
- Существующие коллекции не удаляем; доменные данные размещаем в `krug_*`, демоданные явно помечаем.

## Проверки и ограничения

Домен — 8 тестов, MongoDB Круга — 10, API студии — 9; пройдены. Браузерная проверка production-сборки: все 5 сценариев прошли (51,9 секунды), включая desktop/mobile и исходный Data Studio. Пройдены typecheck, lint и production build. Контраст токенов: 14/14.

Полностью остановлены и повторно запущены MongoDB, API и Next.js; сохранённые заявки, решения кругов и настройки студии совпали с контрольным снимком. Команда `npm run dev` проверена и оставлена работающей на http://127.0.0.1:3000. Исправлены учёт отказов в общих метриках и сохранение выбранной заявки на границе лимита 250 узлов; проверены интеграционно.

Черновик сохраняется при смене ширины в текущей вкладке; до публикации перезагрузка его не сохраняет. Гостевой профиль привязан к браузеру. Нет чата, публичной авторизации и подтверждения физической передачи. Проверка на реальных телефонах и просмотр командой остаются следующими действиями.

# Как включить Material Design для «Круга»

В проект добавлен навык `krug-material-design`. Он содержит визуальные правила Material Design 3, палитру, типографику, формы, состояния компонентов, адаптивную композицию и правила изображения обменного круга.

Выбранный стек: **Framework7 React с Material-темой `md` для мобильной версии, Material UI для десктопа**. API, сессии, бизнес-правила и дизайн-токены общие.

## Короткая активация

Отправь Codex конкретную задачу вместе с названием навыка:

```text
$krug-material-design

Оформи интерфейс «Круга» в Material Design 3:
зелёная тема, мягкие тональные поверхности, выразительная типографика,
округлые Material-компоненты и аккуратная анимация состояний.
Мобильную версию сделай на Framework7 React с theme: 'md', десктоп — на Material UI.
Примени общие токены и проверь обе оболочки.
Сохрани текущую бизнес-логику и работающие действия.
```

Можно написать обычными словами: **«Активируй Material Design для Круга»** и дальше указать экран или задачу. Маршрут к навыку закреплён в `AGENTS.md`.

## Полная реализация проекта с дизайном

```text
$krug-material-design

Прочитай docs/krug-codex-prompt.md и реализуй проект «Круг» по этому заданию.
Для интерфейса используй навык krug-material-design.
Мобильная версия — Framework7 React с Material-темой; десктоп — Material UI.
Сначала определи тему и переиспользуемые компоненты, затем примени их
к каталогу, форме заявки, результатам поиска и странице обменного круга.
Доведи пользовательский сценарий до рабочего состояния и проведи проверки.
```

## Один экран

```text
$krug-material-design

Разработай страницу обменного круга на 2–4 участников в стиле Material Design 3.
Выдели текущего пользователя, покажи «Вы отдаёте» и «Вы получаете»,
читаемые направленные связи, реальные ответы участников и следующий шаг.
Для телефона используй Framework7 React с theme: 'md', для desktop — Material UI.
Сделай общие API, состояние и токены для обеих композиций.
```

Если экран ещё не реализован, навык помогает его создать в рамках указанной задачи. Если нужен редизайн существующего экрана, назови его адрес или компонент.

## Визуальное ревью

```text
$krug-material-design

Проведи визуальное ревью текущего интерфейса «Круга».
Проверь Material-иерархию, контраст, длинные русские тексты,
формы, состояния ошибок, клавиатуру и мобильный экран.
Дай конкретные замечания по важности. Пока не меняй код.
```

## Если навык не появился в списке

Codex обнаруживает проектные навыки в `.agents/skills`. Если новый навык не отображается, открой новый сеанс или перезапусти Codex. Для немедленного использования подходит прямой промпт:

```text
Прочитай .agents/skills/krug-material-design/SKILL.md и следуй этому навыку.
Используй только нужные справочники, указанные в нём.
Примени Material Design 3 к интерфейсу «Круга» в рамках моей задачи.
```

Файлы навыка хранятся в репозитории, поэтому он передаётся вместе с проектом. Активация не требует токена, облачного подключения или отдельного плагина.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `.agents/skills/krug-material-design/SKILL.md` | Входная инструкция, область применения и выбор нужных материалов. |
| `references/design-system.md` | Цветовые роли, типографика, формы, композиция и обменная схема. |
| `references/react-integration.md` | Условия подключения Material UI к существующему Next.js. |
| `references/framework7-mobile.md` | Мобильная оболочка Framework7 React, маршрутизация, стили и жизненный цикл. |
| `references/visual-review.md` | Проверка экранов и пользовательских состояний. |
| `assets/krug-material-tokens.json` | Начальная светлая палитра и токены проекта. |
| `scripts/check-contrast.mjs` | Проверка контраста базовых непрозрачных цветовых пар. |

Пути `references/`, `assets/`, `scripts/` в таблице относятся к папке навыка.

Проверка стартовой палитры:

```bash
node .agents/skills/krug-material-design/scripts/check-contrast.mjs
```

Для изменённого JSON в таком же формате можно передать путь последним аргументом. Успешная проверка токенов не заменяет просмотр реально отрисованных экранов.

Основа навыка — [цветовые роли Material](https://material-web.dev/theming/color/), [типографика](https://material-web.dev/theming/typography/) и [интеграция MUI с Next.js](https://mui.com/material-ui/integrations/nextjs/). Подключение проектных навыков и вызов через `$` описаны в [официальной инструкции Codex](https://learn.chatgpt.com/docs/build-skills).

Для мобильного стека используются [официальная установка Framework7 React](https://framework7.io/react/installation), [инициализация](https://framework7.io/react/init-app) и [параметры темы Framework7](https://framework7.io/docs/app).

Пороговые значения проверки контраста опираются на пояснения W3C для [обычного текста](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) и [существенных элементов интерфейса](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html).

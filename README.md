# Круг

Сервис многостороннего обмена вещами во Владивостоке. Человек указывает, что отдаёт и что хочет получить; приложение ищет допустимые круги из 2–4 участников. Рабочий локальный MVP: заявки → подбор → схема передач → ответы → резервирование вещей при общем согласии.

На компьютере используется Material UI, на телефоне — Framework7 React с темой Material. Обе оболочки используют одну сессию, API, MongoDB и черновик формы. Существующий конструктор MongoDB сохранён на `/studio`.

## Быстрый запуск

Нужны Node.js 22 LTS (`.nvmrc`), npm, установленный MongoDB Community Server (`mongod`). Для браузерных проверок нужен Google Chrome. На текущем компьютере зависимости и MongoDB уже установлены.

```bash
nvm use
npm ci
cp .env.example .env
npm run dev
```

Если `.env` уже настроен, сохраните его. Команда запускает MongoDB, Express и Next.js; API ждёт готовности базы, создаёт индексы и при `DEMO_MODE=true` идемпотентно добавляет демонабор. Первый старт может занять несколько секунд. Остановка — `Ctrl+C`.

| Что | Где |
| --- | --- |
| Круг | http://127.0.0.1:3000 |
| Data Studio | http://127.0.0.1:3000/studio |
| Проверка API | http://127.0.0.1:4000/api/krug/health |
| MongoDB | `mongodb://127.0.0.1:27018/?replicaSet=krug-rs` |
| База | `vibe_farpost` |
| Файлы и журнал MongoDB | `.local/mongodb/`, `.local/mongodb.log` |

Все процессы слушают `127.0.0.1`. Next.js проксирует `/api/krug/*` и `/api/db/*` на Express. Браузер не получает URI MongoDB.

## MongoDB и сохранность

`scripts/mongodb.mjs` запускает локальный **single-node replica set** `krug-rs` и однократно инициализирует его. Это необходимо для настоящих MongoDB-транзакций. Скрипт использует прежний каталог данных; не удаляет базу при старте. Реплика из одного узла обеспечивает транзакции, но не отказоустойчивость.

При переходе существующей standalone-базы: остановите прежний `mongod`, сделайте резервную копию каталога данных, проверьте `replicaSet=krug-rs` в `.env` и запускайте `npm run dev`. Не запускайте два процесса на одном dbpath. В этой рабочей копии перед переходом сохранена офлайн-копия `.local/backups/mongodb-pre-krug-20261113`.

Для другого бинарника задайте `MONGOD_BINARY`. При смене порта меняйте `MONGODB_LOCAL_PORT` и порт в `MONGODB_URI`; существующая конфигурация replica set также должна соответствовать адресу. Для внешнего replica set задайте URI и запускайте отдельно API и Next.js, без `db:dev`.

`.local/` и `.env` исключены из Git. Обычные перезапуски сохраняют заявки и ответы. Домен хранится в `krug_*`; универсальный API студии запрещает чтение и запись этих коллекций. Другие коллекции и их конструктор форм сохранены.

## Первая демонстрация

1. Выберите демопрофиль **Анна · A**. При необходимости нажмите «Сбросить демо».
2. «Предложить вещь»: название «Монитор Samsung 24 дюйма», тип «Монитор», описание от 10 символов, пожелание «Хочу велосипед». Выберите желаемый тип «Велосипед». Районы встречи можно оставить без ограничений.
3. Опубликуйте, нажмите «Найти мой круг». Появятся два круга по три человека. Прямой пары для Анны нет.
4. Выберите круг с Верой и Борисом: Анна отдаёт монитор Вере и получает велосипед Бориса. Подтвердите интерес.
5. В других браузерных профилях либо через явно обозначенный демопереключатель подтвердите интерес за Веру и Бориса. Статус станет «Все согласны», три вещи зарезервируются.
6. Для отдельного сценария отказа сбросьте демо, повторите добавление и откажитесь за Бориса. Новый подбор Анны предложит Дашу и Глеба.

Seed создаёт **12 демопрофилей и 11 заявок B–L**. Заявка Анны A создаётся обычной формой. Егор F показывает круг на 4, Лена J — прямой обмен, Никита L — отсутствие варианта. Полный [сценарий защиты](docs/demo-script.md).

```bash
npm run demo:seed    # идемпотентное добавление, без отката изменений
npm run demo:reset   # удаляет только помеченные демоданные и создаёт исходный набор
```

Reset удалит также заявки, введённые под демопрофилем, и закроет связанные активные круги. Данные обычных профилей и произвольные коллекции сохранятся. Для работы без демопереключателя установите `DEMO_MODE=false`; создайте локальный профиль кнопкой «Представиться».

## Команды

```bash
npm run db:dev          # MongoDB + инициализация replica set
npm run server:dev      # Express с обновлением
npm run web:dev         # Next.js
npm run db:init         # индексы, при уже запущенной MongoDB
npm run typecheck
npm run lint
npm run test:domain     # чистая логика, MongoDB не нужна
npm run test:krug       # сессии, транзакции, гонки; MongoDB должна работать
npm run test:db         # сохранённые проверки Data Studio
npm run test:ui         # приложение и Chrome должны работать
npm run benchmark:krug  # воспроизводимое измерение, .local/qa/benchmark.json
npm run styles:scope    # пересоздать изолированные CSS после обновления Framework7
npm run build
```

Интеграционные тесты создают и удаляют только собственные временные базы. Браузерные тесты Круга **сбрасывают демонстрационный набор** в настроенной базе; запускайте их на локальной демокопии. Studio-тест создаёт и удаляет собственную коллекцию `ui_check_*`. По умолчанию используется Chrome; `PLAYWRIGHT_CHANNEL` и `APP_URL` меняют браузер и адрес. Скриншоты лежат в `.local/qa/`, отчёты ошибок — в `test-results/`.

Для production-сборки локально: в одном терминале `npm run db:dev`, в другом `npm run build && npm start`. Перед этим остановите dev API и Next.js, чтобы освободить порты.

## Структура

- `shared/krug/` — DTO, справочники, строгие схемы ввода.
- `server/domain/krug/` — сопоставление, общие условия, ориентированный граф, DFS и фикстуры.
- `server/repositories/`, `server/services/` — MongoDB, сессии, транзакции, демоданные.
- `server/routes/krug.ts` — доменный API; старые маршруты студии сохранены.
- `src/components/krug/` — общий контроллер и экраны, desktop MUI и mobile Framework7.
- `src/theme/krug-tokens.json` — общие токены; `scripts/scope-styles.mjs` изолирует CSS.
- `src/components/database/` — прежний Data Studio.

## Границы MVP

Локальная сессия узнаёт браузер, а не подтверждает личность человека. Доступны текстовые заявки и объяснимое сопоставление по справочнику типов, словам и строгим ограничениям; внешней LLM нет. Поиск ограничен 250 активными заявками, глубиной 4, 100 000 шагов и бюджетом времени; неполный результат явно помечается. Это не глобально оптимальное распределение всех вещей.

Владивосток представлен зонами встречи; маршруты, мосты, пробки и время в пути автоматически не рассчитываются. Окна встречи показываются по времени Владивостока. Нет чата, реальных контактов, фото, платежей, верификации и статуса физически завершённой передачи. Все согласия означают интерес и резерв на 24 часа по умолчанию. Истечение обрабатывается при обращении к API; фонового планировщика пока нет.

Публичный хостинг потребует отдельной настройки аутентификации, HTTPS, ограничений доступа к студии и эксплуатации MongoDB. Текущий запуск рассчитан на локальный прототип.
